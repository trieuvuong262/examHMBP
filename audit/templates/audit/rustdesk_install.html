Cài RustDesk trên máy này

Server: {{ rustdesk_public_host }} — sau khi chạy script, máy sẽ tự đăng ký lên menu RustDesk.

Bước 1 — Tải file cài đặt

File đã nhúng cấu hình Portal (secret, public key, mật khẩu client). Mỗi lần tải có thể dùng lại trên nhiều máy cùng cấu hình.

Tải cho Windows (.zip) Tải cho Linux (.sh)
Bước 2 — Chạy file
  • Windows: Giải nén JustPlay-RustDesk-Setup-win.zip vào thư mục cố định (ví dụ Desktop\RustDesk), chuột phải JustPlay-RustDesk-Setup.cmd → Run as administrator. Không chạy trực tiếp từ file zip trong Downloads.
  • Linux Mint: Mở Terminal, vào thư mục đã tải: chmod +x JustPlay-RustDesk-Setup.sh && ./JustPlay-RustDesk-Setup.sh (script sẽ tự hỏi sudo nếu cần).

Script sẽ: cài RustDesk (nếu chưa có) → trỏ về {{ config.rustdesk_host }} → đặt mật khẩu → gửi ID lên Portal.
