Cài JustPlay Agent (EXE)

1 file EXE trên mỗi PC — tự quét WMI local, gửi lên VPS. Không cần domain, không cần relay.

Cài tự động khi đăng nhập portal

User Windows lần đầu đăng nhập sẽ thấy popup — tải 1 file .cmd đã gắn tài khoản, chạy file → sau ~5 giây PC tự quét và gửi lên module thiết bị.

IT: đặt JustPlayAgent.exe lên server tại static/equipment/ hoặc EQUIPMENT_AGENT_EXE_PATH trong .env.

Cách hoạt động
  1. Cài JustPlayAgent.exe + file justplay_agent.ini trên từng PC.
  2. Agent tự chạy khi đăng nhập Windows, gửi serial/IP/cấu hình lên portal.
  3. Trên portal bấm Quét tất cả PC → mọi agent online báo cáo lại trong 1–2 phút.
① VPS (.env)
EQUIPMENT_AGENT_SECRET=mat-khau-bi-mat-tu-dat
PORTAL_PUBLIC_BASE_URL=https://portal.justplay.vn
{% if not has_agent_secret %}

Chưa có EQUIPMENT_AGENT_SECRET trên server.

{% endif %}
② Build EXE (máy dev, 1 lần)
pip install pyinstaller
scripts\build-justplay-agent.cmd

File: static/equipment/JustPlayAgent.exe

③ Cài trên từng PC (copy 2 file)

Tạo thư mục C:\JustPlayAgent\ gồm:

  • JustPlayAgent.exe
  • justplay_agent.ini (copy từ justplay_agent.ini.example)
[portal]
url=https://portal.justplay.vn
secret=mat-khau-bi-mat-tu-dat

[agent]
interval_minutes=30
poll_seconds=60

Cài tự chạy khi login:

scripts\install-justplay-agent.cmd "C:\JustPlayAgent"

Test tay: JustPlayAgent.exe --once
