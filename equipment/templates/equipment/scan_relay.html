Quét thiết bị (relay IT)

Bấm Quét trên portal → VPS gọi máy Windows IT → WMI trong LAN (giống hospital).

{% include 'equipment/includes/subnav.html' %}
Luồng hoạt động
  1. IT bấm Quét trên danh sách thiết bị (portal VPS).
  2. VPS gửi lệnh qua Tailscale tới scan_relay_server.py trên máy IT.
  3. Máy IT quét WMI dải IP / thiết bị đã chọn trong LAN.
  4. Portal cập nhật DB — không cài gì trên PC nhân viên.
Bước 1 — VPS (.env)
EQUIPMENT_RELAY_HTTP_URL=http://100.x.x.x:8765
EQUIPMENT_RELAY_SECRET=chuoi-bi-mat-giong-agent
EQUIPMENT_SCAN_DEFAULT_USER=JUSTPLAY\it-admin
EQUIPMENT_SCAN_DEFAULT_START_IP=192.168.1.1
EQUIPMENT_SCAN_DEFAULT_END_IP=192.168.1.254

100.x.x.x = IP Tailscale máy IT. Secret khớp scan_relay.env.

Bước 2 — Máy Windows IT
copy scan_relay.env.example scan_relay.env
python scan_relay_server.py

# Tự chạy khi login:
.\scripts\setup-scan-relay-server.ps1 -ProjectDir "D:\Project\PortalJustPlay"
Bước 3 — Quét theo lịch (tuỳ chọn)
.\scripts\setup-scan-relay-task.ps1 -ProjectDir "D:\Project\PortalJustPlay"

Chạy scan_relay.py định kỳ không cần bấm trên web.
