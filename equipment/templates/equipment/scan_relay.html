Quét thiết bị tập trung (scan relay)

Production VPS: quét WMI từ 1 máy Windows IT trong LAN — không cài trên từng PC.

{% include 'equipment/includes/subnav.html' %}
Cách hoạt động
  1. Máy Windows IT (cùng LAN xưởng) chạy scan_relay.py.
  2. Script quét dải IP bằng WMI + tài khoản domain admin.
  3. Kết quả gửi lên portal qua API /thiet-bi/api/agent-report/.
  4. Danh sách thiết bị trên portal tự cập nhật IP, cấu hình, trạng thái online.
Bước 1 — VPS (.env)
EQUIPMENT_AGENT_SECRET=chuoi-bi-mat-dai-ngau-nhien
PORTAL_PUBLIC_BASE_URL=https://portal.justplay.vn
{% if not has_agent_secret %}

Chưa cấu hình EQUIPMENT_AGENT_SECRET trên server.

{% endif %}
Bước 2 — Máy Windows IT

Trong thư mục project (clone hoặc copy 2 file):

copy scan_relay.env.example scan_relay.env
# Sửa scan_relay.env: URL, secret, dải IP, SCAN_USER / SCAN_PASS

python scan_relay.py --dry-run
python scan_relay.py
Bước 3 — Tự động (Task Scheduler)

PowerShell (Admin) trên máy IT:

Set-ExecutionPolicy -Scope Process Bypass
.\scripts\setup-scan-relay-task.ps1 -ProjectDir "D:\Project\PortalJustPlay"

Task chạy khi đăng nhập Windows + lặp mỗi 2 giờ.
