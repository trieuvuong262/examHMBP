Ứng dụng mở nhanh từ Desktop / Start — dùng sau khi cài Agent.

Đang chờ trình duyệt cho phép cài…

Microsoft Edge
  1. Thanh địa chỉ: biểu tượng ⊕ Cài đặt hoặc Ứng dụng có sẵn
  2. Hoặc menu ⋯ → Ứng dụng → Cài trang web này
Google Chrome
  1. Thanh địa chỉ: ⊕ Cài đặt / Install
  2. Hoặc menu ⋮ → Cài đặt → Cài trang web dưới dạng ứng dụng
