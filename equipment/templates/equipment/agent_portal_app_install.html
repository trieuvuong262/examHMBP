Cài JustPlay Portal

Ứng dụng mở nhanh từ Desktop / Start — dùng sau khi cài Agent.

Đã cài ứng dụng — mở từ Start hoặc Desktop.

Đang chờ trình duyệt cho phép cài…

Microsoft Edge
  1. Menu ⋯ (góc phải) → Ứng dụng → Cài JustPlay Portal
  2. Hoặc ⋯ → More tools → Apps → Install JustPlay Portal
  3. Hoặc thanh địa chỉ: ⊕ Cài đặt
Google Chrome
  1. Menu ⋮ → Cài đặt (Install) → Cài JustPlay Portal
  2. Hoặc ⋮ → More tools → Apps → Install JustPlay Portal

Nếu không thấy mục cài: vào trang chủ portal, đợi 5 giây, tải lại trang rồi thử lại.
