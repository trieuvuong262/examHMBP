{% load static %} Dành cho nhân viên

Module Thư viện gồm 2 phần: Tài liệu (xem file nội bộ) và Hỏi đáp (trợ lý AI tra cứu quy trình theo tài liệu bạn được phép đọc).

1
Menu Thư viện → Tài liệu. Trang hiện thư mục theo phòng ban / danh mục HR đã cấu hình — bạn chỉ thấy file thuộc quyền của mình.
2
Dùng ô Tìm kiếm hoặc bấm từng thư mục để lọc. Tên file thường kèm ngày ban hành hoặc mã quy trình.
3
Bấm tên file → xem PDF/Word/ảnh ngay trong trình duyệt. Cần lưu máy → bấm Tải xuống (nếu có nút).
4
Chuyển sang menu con Hỏi đáp → gõ câu hỏi bằng tiếng Việt tự nhiên, ví dụ: "Quy trình xin nghỉ phép như thế nào?"
5
Trợ lý AI trả lời dựa trên tài liệu bạn được xem — kèm trích dẫn nguồn. Đọc kỹ đoạn trích; nếu chưa đủ, hỏi tiếp trong cùng phiên chat.
6
Không tìm thấy tài liệu cần → liên hệ HR/IT để được cấp quyền thư mục hoặc bổ sung file.
Mẹo: Hỏi cụ thể (tên quy trình, tình huống) thay vì câu chung chung — AI trả lời chính xác hơn.

Dành cho HR / Quản trị
7
Vào Tài liệu → khu vực quản trị (nếu có quyền) → Tải lên file PDF/Word, chọn thư mục và phòng ban được xem.
8
Đặt tên file rõ ràng (mã quy trình + phiên bản). Cập nhật bản mới → tải file mới, không xóa bản cũ nếu cần lưu lịch sử.
9
Kiểm tra quyền menu Hỏi đáp trong nhóm quyền — nhân viên cần quyền xem tài liệu thì AI mới trả lời được.
10
Cấu hình trợ lý AI (prompt, model) tại Quản trị hệ thống → Trợ lý AI nếu cần tinh chỉnh cách trả lời.
